# YT Music Enchanced

## Install

```python
#~ npm install
#~ npm start
```

## Dependencies

- [Electron](https://github.com/electron/electron)
- [Typescript](https://typescriptlang.org/)
- [YT Enchanced](https://github.com/korex71/Enchanced-yt)

## Features

- **Discord Rich Presence** – set `DISCORD_CLIENT_ID` before starting the app to show the current track to friends.
- **Custom CSS/JS** – add `src/assets/custom.css` and/or `src/assets/custom.js` to tweak the interface.
